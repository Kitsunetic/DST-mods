# DST mods

Development repository for Don't Starve Together mods. Each mod has its own directory.

## Mods

- [Extra Equip Slots (Bug Fixing Addon)](<Extra Equip Slots (bug fixing addon)/README.md>) — fixes backpack overflow and open-container crafting when used with [Extra Equip Slots (Updated, Wilson: fix beard)](https://steamcommunity.com/sharedfiles/filedetails/?id=3681081494).

The addon contains no files from the original Workshop mod. See its README for installation and verification status.
